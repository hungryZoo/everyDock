# everyDock v0.3.0 — Public Beta

Apple Silicon · macOS 26 이상에서 각 모니터에 항상 표시되는 Dock 유틸리티입니다.

## 설치

Homebrew 6 기준:

```sh
brew tap hungryZoo/tap
brew trust --cask hungryZoo/tap/everydock
brew install --cask hungryZoo/tap/everydock
open -a everyDock
```

## 포함 기능

- 화면별 Dock, 고정 앱·실행 상태, 포인터 확대와 실행 반응.
- 기본 Dock 크기 연동, macOS 유리 배경, 기본 Dock 설정 관리·복원 감시.
- 실제 창 최소화·복원 요청, 호버 창 미리보기와 창 선택.
- 바탕화면 보기/복원, 다운로드 스택, 사용자 휴지통·파일 드롭.
- MRD·PRD·SRS·TC 개발 문서, arm64 빌드·패키징 CI.

## 베타 제약

- 바이너리는 ad-hoc 서명되었으며 Apple 공증이 없습니다. 첫 실행이 차단되면 배포 출처를 확인하고 macOS 개인정보 보호 및 보안에서 실행을 직접 승인하세요. 보안 보호를 해제하는 명령을 설치 과정에 넣지 않습니다.
- 창 최소화·개별 창 선택은 손쉬운 사용, 창 이미지는 화면 기록 권한이 필요합니다. 업데이트 후 권한 재등록이 필요할 수 있습니다.
- 실제 권한 허용 후 최소화 애니메이션·캡처·창 선택 및 다운로드 파일 처리에는 미검증 항목이 있습니다. 상세 상태는 docs/TC.md를 참고하세요.
- 요술램프 도착점은 macOS가 결정하며 각 everyDock 아이콘으로 지정하지 않습니다. 시스템 Dock과 픽셀 단위 동일성을 보장하지 않습니다.
- 휴지통 비우기는 현재 사용자 계정의 휴지통만 대상으로 합니다. 외장 드라이브 휴지통은 Finder에서 관리하세요.

자동 테스트 10개 및 arm64 빌드·번들 서명 검증을 수행한 초기 배포본입니다. 안정 버전 인증이나 모든 수동 테스트 통과를 의미하지 않습니다. SHA256SUMS로 ZIP 무결성을 확인할 수 있습니다.
