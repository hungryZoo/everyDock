# everyDock 0.3.2 — 창 관리와 메뉴 개선

- 아이콘을 기준으로 우클릭 메뉴를 배치하고 메뉴가 열린 동안 확대 위치를 고정합니다. 앱 이름 상자의 글자를 세로 중앙에 맞췄습니다.
- AX 실제 창을 기준으로 미리보기를 구성하여 캡처 보조 창·제목 변경 때문에 카드가 중복되는 문제를 수정했습니다. 동명 창 선택도 객체로 구분합니다.
- Finder를 포함한 앱 메뉴의 **모든 창 닫기**, 미리보기 카드별 **×**, 호버 없이 여는 **열린 창 보기…**를 추가했습니다.
- 창이 없는 앱의 다시 열기와 팝업을 닫은 뒤 같은 앱에서 다시 열기를 수정했습니다. 저장 확인이 나오면 일괄 닫기를 멈춥니다.

기존 확대 렌더러(NSControl·캐시·화면 동기화)를 유지합니다. 자동 테스트 25개 통과. 실기기 검증 범위와 남은 항목은 [QA](../QA-v0.3.2.md)를 참조하세요. Apple Silicon·macOS 26 이상, ad-hoc 서명 공개 베타이며 공증되지 않았습니다.

정상 종료 후:

```sh
brew update
brew upgrade --cask hungryZoo/tap/everydock
open -a everyDock
```

업데이트 후 실제 OS 요청이 거부되면 시스템 설정에서 현재 설치 앱의 손쉬운 사용·화면 기록 권한을 재등록해야 할 수 있습니다. 이미지 권한이 없어도 AX 허용 상태에서는 제목으로 창을 선택·닫을 수 있습니다.
