# everyDock 0.3.4 — 앱 고유 메뉴 위치 수정

- ‘앱 고유 메뉴…’ 또는 Option-우클릭으로 macOS Dock에서 읽은 앱 메뉴를 현재 everyDock 아이콘 옆에 표시합니다.
- 다른 모니터라는 이유로 메뉴를 차단하거나 설정 창 경고를 띄우지 않습니다.
- 비활성 항목·체크 표시·하위 메뉴를 구분하고 선택한 명령을 실제 Dock에 전달합니다. 내용이 바뀌면 실행을 중단합니다.
- 접근 실패는 일반 everyDock 메뉴 안에서 안내합니다.

손쉬운 사용 권한과 기본 Dock의 해당 앱 항목이 필요합니다. 조회·전달 중 원래 시스템 메뉴가 잠시 나타날 수 있습니다. 실제 검증 범위는 [QA](../QA-v0.3.4.md)를 참고하세요. Apple Silicon·macOS 26 이상, ad-hoc 서명 공개 베타입니다.

정상 종료 후:

```sh
brew update
brew upgrade --cask hungryZoo/tap/everydock
open -a everyDock
```

업데이트 후 실제 접근이 거부되면 현재 설치 앱의 손쉬운 사용·화면 기록 등록을 갱신해야 할 수 있습니다.
