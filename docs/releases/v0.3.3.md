# everyDock 0.3.3 — 팝업과 확대 창 개선

- 창 1개 미리보기는 1열로 맞추고 창 개수가 바뀌면 팝업 크기를 갱신합니다.
- 바탕화면 버튼은 다운로드처럼 바탕화면 파일 팝업을 엽니다. 앱을 숨기지 않습니다.
- Apps 아이콘에서 설치 앱을 검색하고 실행할 수 있습니다.
- 화면 크기로 확대된 일반 창은 everyDock 영역을 남기도록 보정합니다. 손쉬운 사용 권한이 필요하며 전체 화면·최소화·일반 크기의 창은 제외합니다. AX 미지원 앱과 앱 자체 최소 크기 제약은 적용이 제한될 수 있습니다.

자동 테스트 31개 PASS. 실기기 검증 범위는 [QA](../QA-v0.3.3.md)를 참고하세요. Apple Silicon·macOS 26 이상, ad-hoc 서명 공개 베타이며 공증되지 않았습니다.

정상 종료 후:

```sh
brew update
brew upgrade --cask hungryZoo/tap/everydock
open -a everyDock
```

수정본에서 실제 접근이 거부되면 현재 설치 앱의 손쉬운 사용·화면 기록 등록을 갱신해야 할 수 있습니다. 바탕화면 파일 접근은 macOS의 폴더 접근 승인을 따릅니다.
