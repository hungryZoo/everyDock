# everyDock v0.3.8

- 처음 실행하면 권한과 로그인 자동 실행을 준비하는 안내 창이 열립니다. 손쉬운 사용·화면 녹화 설정, 허용 상태 재확인, 현재 앱 위치를 제공합니다.
- 최초 안내에서 자동 실행을 선택하고 ‘시작하기’를 누르면 로그인 항목에 등록합니다. ‘나중에 설정’은 로그인 상태를 바꾸지 않습니다. 기존 사용자의 로그인 선택은 유지합니다.
- 설정에 ‘초기 설정 안내 다시 열기…’와 ‘메뉴 막대 아이콘 가리기’를 추가했습니다.
- 아이콘을 숨겨도 앱 메뉴(Apps)에서 everyDock을 실행하면 설정을 열 수 있습니다. 로그인 자동 실행은 설정 창 없이 시작합니다.

자동 검사 45개와 arm64 패키징·서명 검사를 통과했습니다. 실제 UI·권한·로그인 검증 범위는 [QA 기록](https://github.com/hungryZoo/everyDock/blob/main/docs/QA-v0.3.8.md)을 확인하세요.

Apple Silicon·macOS 26 이상. ad-hoc 서명 공개 베타이며 Apple 공증은 없습니다. 업데이트 전에 everyDock을 정상 종료하고 `brew update`와 `brew upgrade --cask everydock`을 실행하세요. 업데이트 후 기존 권한이 거부되면 초기 안내 또는 README의 현재 앱 재등록 절차를 따르세요.
