# everyDock 0.3.6 — 구분선과 폴더 썸네일 개선

- 고정 앱·고정하지 않은 실행 앱·폴더를 자동 구분선으로 나눕니다.
- 고정 앱 사이 우클릭이나 앱 메뉴의 앞/뒤 추가로 임의 구분선을 넣을 수 있습니다. 설정의 고정 앱 목록에서 앱과 함께 이동·삭제하며 재실행해도 유지합니다.
- 폴더 재열기 중 기존 썸네일을 유지합니다. 이전 팝업의 종료가 새 팝업 작업을 취소하지 않도록 하고, 응답 없는 썸네일이 후속 파일을 계속 막지 않도록 보완했습니다.

임의 구분선은 고정 영역에 저장합니다. 실제 검증 범위는 [QA](../QA-v0.3.6.md)를 참고하세요. Apple Silicon·macOS 26 이상, ad-hoc 서명 공개 베타입니다.

정상 종료 후:

```sh
brew update
brew upgrade --cask hungryZoo/tap/everydock
open -a everyDock
```
