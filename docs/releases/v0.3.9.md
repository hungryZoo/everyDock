# everyDock v0.3.9

- 일반 Homebrew 삭제와 재설치가 고정 앱·구분선·모양·메뉴 막대 옵션·첫 실행 기록을 초기화합니다. 앱 종료와 기본 Dock 복원 후 로그인 등록도 해제합니다.
- `brew upgrade`는 기존 설정을 보존합니다. 이전 설치자는 먼저 v0.3.9로 업그레이드해야 새 제거 규칙이 적용됩니다.
- 앱을 실행하거나 다시 열 때 실제 권한을 검사합니다. 이전에 안내를 완료했어도 권한이 없거나 확인에 문제가 있으면 설정 안내 창이 열립니다.
- macOS의 권한 승인 기록은 앱 설정과 별도이며 자동 삭제하지 않습니다.

자동 검사 47개, arm64 패키징·서명 검사, 실제 Homebrew fixture의 업그레이드 보존 및 재설치·삭제 초기화 검사를 통과했습니다. 실제 수행 범위는 [QA 기록](https://github.com/hungryZoo/everyDock/blob/main/docs/QA-v0.3.9.md)을 확인하세요.

Apple Silicon·macOS 26 이상. ad-hoc 서명 공개 베타이며 Apple 공증은 없습니다. 업데이트는 `brew update` 후 `brew upgrade --cask everydock`을 사용하세요.
