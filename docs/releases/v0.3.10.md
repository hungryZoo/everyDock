# everyDock v0.3.10

- 초기 실행 시 화면 기록 권한 창이 자동으로 뜨던 문제를 수정했습니다. 시작·재열기·일반 상태 확인에서는 화면 캡처 API를 호출하지 않습니다.
- 권한이 없으면 호버 미리보기도 화면 접근을 요청하지 않습니다. 화면 녹화 권한 버튼을 눌렀을 때만 요청하며, 거부 후 백그라운드에서 반복 요청하지 않습니다.
- 초기 안내 하단의 중복 재확인·앱 위치·재등록·폴더 설명 영역을 제거하고 창을 줄였습니다. 상세 도움말은 일반 설정과 README에서 확인할 수 있습니다.

자동 검사 49개와 arm64 패키징·서명 검사를 통과했습니다. 실제 수행 범위는 [QA 기록](https://github.com/hungryZoo/everyDock/blob/main/docs/QA-v0.3.10.md)을 따릅니다.

Apple Silicon·macOS 26 이상, ad-hoc 서명 공개 베타. 업데이트는 `brew update` 후 `brew upgrade --cask everydock`을 사용하세요. `brew reinstall`은 설정을 초기화합니다.
