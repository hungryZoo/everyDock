# everyDock v0.3.1 — 권한 진단과 애니메이션 개선

권한을 허용했는데도 최소화와 미리보기가 차단되던 안내를 수정하고 확대 렌더링의 반복 작업을 줄였습니다.

- 실제 AX/ScreenCaptureKit 응답으로 권한을 판단합니다. 창 없음·미지원·응답 지연을 권한 거부와 구분하며 재검사와 현재 앱 위치 확인을 제공합니다.
- 확대를 화면별 CADisplayLink로 동기화하고, 아이콘·실행 표시를 캐시된 레이어와 셀 없는 아이콘 컨트롤로 표시합니다. 안정되면 프레임 갱신을 멈춥니다.
- 앱 전체 속성 조회를 백그라운드로 옮기고 이벤트를 병합했습니다. 포인터마다 환경변수 조회·동일 WindowServer 설정 전송·동일 패널 배치를 반복하던 작업을 제거했습니다.
- 코드와 docs를 같은 변경 단위에서 유지하는 저장소 규칙, MRD·PRD·SRS·TC와 회귀 테스트 7개를 추가/갱신했습니다.

```sh
# everyDock 정상 종료 후
brew update
brew upgrade --cask hungryZoo/tap/everydock
open -a everyDock
```

Apple Silicon · macOS 26 이상. 기존 설치가 없다면 README의 tap/trust/install 절차를 사용하세요.

이 베타는 ad-hoc 서명이며 Apple 공증은 없습니다. 업데이트 후 기존 권한 항목의 서명이 일치하지 않을 수 있습니다. 앱 설정에서 ‘권한 다시 확인’을 실행하고, macOS가 거부하면 앱 종료 후 시스템 설정에서 기존 everyDock 항목을 제거·현재 번들로 재등록한 뒤 실행하세요. 안정적인 배포 서명 도입은 남은 과제입니다.

자동 테스트 17개, arm64 release 패키징·서명 검사, 최종 번들의 실제 AX/SCK 접근 성공을 확인했습니다. 성능 측정 범위와 미검증 항목은 [QA-v0.3.1](https://github.com/hungryZoo/everyDock/blob/main/docs/QA-v0.3.1.md)에 기록했습니다. 모든 앱의 최소화·보호된 창 캡처, 실제 표시 FPS나 CPU 감소율을 보장하지 않습니다. 요술램프 효과와 도착점은 macOS가 결정합니다.

실기기 사용자 확인에서 미리보기·최소화 정상 동작과 최종 확대 움직임 개선을 확인했습니다.
