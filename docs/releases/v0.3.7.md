# everyDock v0.3.7

- ⌘ Command를 누른 채 고정 앱·구분선을 드래그해 순서를 바꿉니다. 파란 삽입선 위치에 놓으면 모든 화면과 설정의 고정 앱 목록에 저장됩니다.
- 고정하지 않은 실행 앱을 고정 영역에 끌어 놓으면 그 위치에 고정합니다.
- Escape 또는 고정 영역 밖에 놓으면 취소합니다. Command-클릭만으로는 앱을 실행하거나 최소화하지 않습니다.
- 드래그 중 확대·미리보기와 설정 저장을 멈추고 놓을 때 한 번만 저장합니다.

자동 검사 43개와 arm64 패키징·서명 검사를 통과했습니다. 실제 Command-드래그와 다중 모니터 전체 행렬의 검증 범위는 [QA 기록](https://github.com/hungryZoo/everyDock/blob/main/docs/QA-v0.3.7.md)을 확인하세요. 드래그 중 자동 스크롤은 지원하지 않으며, 목적지가 숨겨져 있으면 먼저 스크롤합니다.

Apple Silicon·macOS 26 이상. ad-hoc 서명 공개 베타이며 Apple 공증은 없습니다. 업데이트 전에 everyDock을 정상 종료하고 `brew update`와 `brew upgrade --cask everydock`을 실행하세요. 업데이트 후 기존 창 제어·화면 녹화 권한이 거부되면 README의 앱 재등록 안내를 따르세요.
