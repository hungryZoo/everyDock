# everyDock 0.3.5 — 우클릭 메뉴 통합

우클릭 한 번에 앱 고유 항목과 everyDock의 열기·모든 창 닫기·고정 등을 함께 표시합니다. 별도의 ‘앱 고유 메뉴…’ 선택 단계가 사라졌습니다. Control-클릭과 접근성 메뉴 요청도 같은 동작입니다.

실행 중인 앱은 메뉴를 비동기로 읽은 뒤 표시하며, 실행하지 않은 앱은 기본 기능을 바로 표시합니다. 조회 실패 시에도 기본 기능은 유지합니다. 원래 macOS 메뉴가 조회·명령 전달 중 잠시 보일 수 있습니다.

검증 범위는 [QA](../QA-v0.3.5.md)를 참고하세요. Apple Silicon·macOS 26 이상, ad-hoc 서명 공개 베타입니다.

정상 종료 후:

```sh
brew update
brew upgrade --cask hungryZoo/tap/everydock
open -a everyDock
```
